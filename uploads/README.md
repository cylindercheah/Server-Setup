# uploads/

This directory is the home for community-contributed folders and files.

## Structure

Each contributor's material lives in its own sub-folder:

```
uploads/
└── <your-folder-name>/
    ├── README.md          ← describe what is here and how to use it
    └── ...                ← your scripts, configs, docs, etc.
```

## How to add your folder

See [CONTRIBUTING.md](../CONTRIBUTING.md) for step-by-step instructions on uploading a folder via the GitHub web interface, the Git command line, or the GitHub CLI.

## Guidelines

- Create a sub-folder with a descriptive name (e.g., `my-backup-scripts/`).
- Include a `README.md` inside your sub-folder.
- Do not commit secrets or sensitive credentials.
